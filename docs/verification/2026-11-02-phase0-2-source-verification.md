## 四、方法與可重現性

1. 文字層以 PyMuPDF 逐字取座標；直排頁以 x 座標分欄、右起左訖、欄內自上而下重排；橫排頁（book-1）以 y 帶分行。
2. 直排／多欄頁依協議以頁面影像複核：關鍵結構頁（目錄頁、題欄頁、圖片頁、授權頁）以 150–300 DPI 點陣化後經視覺模型（GLM-5V）多次讀取比對；比對不一致者（如 p317 示意圖左右半歸屬）以分半高解析度重測解決，無法解決者列入待審清單。
3. 完整管線見 `scripts/phase0-2/`（extract → analyze → build → validate）；建置輸出（`build-report.txt`）隨資料檔留存。
